Android 基础版支持 Android 8.0 及以上的 64 位设备，目前用于开发测试。

安装 APK 后打开「青简」，点击「启用青简输入法」，在系统列表中启用青简，再点击「切换到青简」。
回到页面的试输入框，键入 `nihao`，点击「你好」上屏；候选下方的 `hello` 是英文译词。

## 使用键盘

- 字母键输入全拼或简拼；横滑候选条查看更多词，点击上屏。
- 空格选择首选候选；没有候选时上屏原始拼音，没有输入时插入空格。
- 回车先上屏原始拼音，再按当前输入框执行发送、搜索或换行。
- 退格先删除拼音；没有拼音时删除选区或光标前的一个字符。
- 「中 / 英」切换拼音与英文直输；「123 / ABC」切换符号与字母；「⇧」让下一个字母大写。
- 逗号和句号在中文模式下先上屏当前输入，再插入中文标点。
- 地球键打开系统输入法选择器。

## 数据与范围

词库、英文译词与输入习惯学习都在本机完成，本版本不连接网络。
密码框只输入原始字符、不记录学习；应用要求不记录学习时青简遵守该要求。
学习数据保存在青简的私有目录，不做系统自动备份；卸载或清除应用数据会删除学习记录。

第一版提供全拼与英文译词，尚无桌面版的双拼 / 五笔设置、神经整句模型、云联想、语音输入或主题设置。
